Glossary

This page defines the terms of this manual, in alphabetical order.

TermDefinition
attemptOne execution of a test item. A retry is a new attempt.
chainA set of test items with the same chain keyword. They run in sequence, on one worker.
combined runOne call to runtests_mono. It runs the suites of several packages of one workspace in one run.
coordinatorThe process that calls runtests. It plans the run, starts the workers and prints the output.
dry runA run with dry_run = true. It prints the plan and runs nothing.
environment directoryA directory under test/ with a Project.toml of its own. The test files in it run in that environment.
evidenceThe files that a failed attempt keeps: the outputs in artifacts_dir() and the files of its producers.
expansionThe test file that chores writes from a test template.
groupA named tag expression in [groups] of test/TestItems.toml.
planThe order in which a run gives out its items, and the worker that is expected to run each item.
producerA function that an item registers with on_failure. It writes evidence after a failed attempt.
profileA named worker configuration in [profiles]: flags, threads, variables, expressions and preferences. An item chooses it with profile = :name.
replayA run of the items of a recorded run state, with its configuration and seeds.
retentionThe rules that decide which run states Runtests keeps.
runOne call to runtests or runtestsf.
run stateA binary file that records one run: its items, results, configuration and seeds.
sandboxAn item with sandbox = true runs alone in a new process, under its profile.
seedThe number from which a run derives the random numbers of each item.
tagA symbol in the tags keyword of an item. A run can select items by tag.
tag expressionA string such as "fast && !slow" that selects items by their tags.
test environmentThe Julia environment in which the items run. It holds the package and its test dependencies.
test fileA file under test/ whose name ends in _test.jl or _tests.jl. It holds @testitem declarations.
test fixtureInput for tests in test/testfixtures/. Runtests never reads it as part of the suite.
test itemA named block of tests, declared with @testitem. It runs alone, in a module of its own.
test setupA module in test/testsetups/ that test items load with using.
union environmentThe environment of the shared workers of a combined run. It holds the test dependencies of all its packages that are not isolated.
test templateA file in test/testtemplates/ of @testtemplate loops. chores expands it into a test file.
verdictThe latest recorded pass or failure of an item. Failures include errors, timeouts and lost-worker outcomes. A skip or explicit cancellation leaves the previous verdict unchanged. See Run states and history.
workerA Julia process that a run starts to run test items.
